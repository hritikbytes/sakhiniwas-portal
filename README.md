## 🚀 Key Features
- **High-Performance Infinite Marquees:** Implemented seamless CSS-only infinite scrolling for student testimonials, providing an immersive, JavaScript-free animation loop.
- **Micro-Interactions & Lottie Integration:** Employed highly optimized Lottie SVG animations for all facility components, bringing the UI alive with dynamic visual feedback without sacrificing page load speeds.
- **Glassmorphism & Ambient Layouts:** Architected a stunning interface using Tailwind CSS background blurs, ambient glow shadows, and custom masonry layouts to ensure maximum visual impact across form factors.
- **Serverless Form Handling:** Fully functional contact routing and inquiry collection handled directly via a transparent Formspree API integration, removing the necessity of maintaining a backend.

## 🛠 Tech Stack
- **Frontend:** HTML5, Tailwind CSS
- **Integrations:** LottieFiles (SVG Animations), Formspree (Serverless Contact Forms)
- **Tools:** Tailwind CLI, NPM, Git

## 📦 Installation & Setup
1. **Clone the repo:** `git clone https://github.com/hritikbytes/hostelwebsite.git`
2. **Install dependencies:** `npm install`
3. **Run the app:** `npm run dev` (This will initialize the Tailwind CLI build compiler and watch for changes)
4. **Build for production:** `npm run build`

## 💡 Technical Challenges & Learning
The central technical hurdle in this project was designing an intricate, seamless architectural layout containing continuous animations, overlapping structural glow elements, and dynamic masonry grids **without** relying heavily on a JavaScript framework like React. By deeply mastering the utility classes provided by **Tailwind CSS**, I orchestrated a highly-responsive environment mimicking a single-page application's feel dynamically. In particular, the CSS-based infinite marquee logic taught me sophisticated keyframe coordination using mask-images for a premium faded-edge aesthetic, greatly elevating my CSS architecture skills.
